🔑 Dropbox の鍵を作る（自動バックアップ用・最初の1回だけ）

ここで入れたものは、このページの外には送りません（Dropbox とのやりとりだけ）。できた鍵は、Supabase の Secrets にだけ入れてください。チャットには書かないでください。

1. アプリの「App key」を入れる

Dropbox のアプリの設定ページ（Settings）にある App key を貼り付けます。
新しいタブで Dropbox が開きます。「許可（Allow）」を押すと、コードが出ます。

2. 出てきたコードを貼り付ける

3. Supabase の Secrets に入れる

Supabase → Edge Functions → Secrets で、次の2つを足します（Name と Value）。
DROPBOX_APP_KEY
DROPBOX_REFRESH_TOKEN
入れ終わったら、このページを閉じてください。
