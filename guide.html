📒 新しい記録簿のお知らせ（内勤のみなさんへ）

11/3 から、記録簿はアプリだけで使います。エクセルの記録簿には書きません。

🌸記録簿アプリ、解禁します

今日から、ポータルは全員、教えてもらった自分の Google アカウントでログインしてください。

新しい記録簿は、直感で使えると思います。入れ忘れが出ないしくみになっているので、安心して使ってみてください。

  • シフトアプリから出されたシフトは、記録簿に自動で入ります。キャストアップがある限り、シフトの手入力は0になりました
  • 確認電話は、時間になるとメールが来るようになりました
  • エクセルの記録簿に入れてあったキャストごとの備考・シフトの特記事項・本日のお知らせは、うつしていません。手があいた時に、11月分（12月も入れた記憶がある人は12月も）をエクセルから手で入れてください
  • 不安な人は、記録簿の上のタブの「🧪 練習」で練習できます。本物と同じ画面（今日のキャストの枠）で受付・精算をためせます。入れたものは本番には入らず、1時間で自動で消えます。お客さんの情報・NG・未精算も変わりません

📝しばらくの間、お願いしたいこと

  1. 11月の予約は、まだアプリに入っていません。手があいた時に、エクセルの11月の記録簿を見ながら、アプリに手で入れてください
  2. キャストのバック・顧客台帳は、しばらくの間エクセルも開いて、合っているか確かめてください。ちがっていたら修正をお願いします
  3. エクセルのコピー・Dropbox の作業は 11/3 までです。昼1の「当月ファイルのエクセル（記録簿・台帳など）を Dドライブにコピー」と「Dropbox にエクセルをアップロード」は、11/3 までやってください。11/4 からはしなくて大丈夫です（記録簿のデータは毎朝自動でバックアップされます）。ただし、当月ファイルのエクセルの中身を変えた時は、Dドライブにもコピーしておいてください
  4. キャッシュフロー・キキララ入出金表は、今までどおりエクセルで入れてください（アプリにするまで、まだ時間がかかります）。この2つは11/4 からも毎日 Dドライブにコピー、キャッシュフローは15日と月末に Dropbox に入れるのも今までどおり続けてください
  5. 精算の時は、お金の写真を必ず残してください。送られてきた写真を精算の画面に貼りつけるか、回収の時にスマホで 記録簿 → 精算 → そのキャストの「📷 写真をとる」で撮ってください（スマホのアルバムには残りません）

🔑入り方

  1. ポータルを開く sakuramoong-app.github.io/portal/
  2. 「Googleでログイン」を押して、自分の Gmail で入る
  3. まんなかの丸いメニュー → 📒 記録簿

上のタブ（受付・精算・顧客台帳…）は、押すと新しいタブで開きます。ほかの人が入れた予約や精算は、自分の画面にも自動で出ます。

☎️受付は、この順番で

  1. 電話番号を入れる → これまでの利用・NG・メモが出ます
  2. 店舗を選ぶ。ダミー店か、それ以外かがいちばん大事です。ダミー店のときは、番号と店舗を入れると選ぶものが出てきます
  3. 名前も必ず入れる。似た名前のお客さんがいると知らせが出ます（番号を変えてくる店NGの人を見つけるため）
  4. キャスト・時間・コースなどを入れて保存

慣れないうちは、まず電話番号 → 店舗。この順番に慣れてください。

👥 予約を取る時は、顧客台帳も見に行くくせをつけてください。受付の画面の「👥 顧客台帳で開く」から、これまでの利用・キャストNG・メモを全部見られます。

🚦受付で出る知らせの色

⚠️ 店NG（出禁）このお客さんは受けません。保存できません。
🙅 キャストNGそのキャストには付けません。ほかのキャストなら受けられます。
📝 お客さんメモエクセル台帳の電話の欄の文字（「こっちから電話かけないで」など）や、⚠️注意の言葉もここに出ます。
📒 エクセルの台帳も確認してくださいはじめての番号・似た番号・似た名前のとき。番号を変えたと言っている、様子があやしいときは、キャストを行かせる前にエクセルの台帳も見てください。

NG がまちがいだったときは、受付の画面の「NGを外す（まちがいだった）」でその場で外せます（スマホでも）。

エクセルの台帳は「見て確かめる用」です。お客さんのことは、アプリの顧客台帳に書きます。

✨エクセルの時から変わったこと

  • 「NG客」は「店NG」と「キャストNG」の2つの呼び方になりました
  • 新規・店リピ・本指名は、これまでの利用から自動で決まります
  • 確認電話：「⏰ この状態の時刻」を入れると、その時刻に受付の画面の上に赤い帯が出て、通知メールも届きます。入れなければ、いつもの時刻（1時間前など）に出ます
  • キャストのバック・報酬は自動で計算します（手で直すこともできます）
  • 出勤時間は、サクラシフトから自動で入ります
  • 細かいデータは、みなさんに直してもらう前提で、あえて完璧にはしていません。「この条件はチェックボックスがいい」「これは表示だけでいい」「NG がまちがって付いている → 外す」など、気づいたら直してください

💴精算

  • キャストから送られてきた写真は、精算の画面にコピーして貼りつけます
  • スマホなら、精算の画面でそのキャストを開いてカメラを押すと、その場で撮れます。写真は自分のスマホには残らず、アプリにそのまま保存されます
  • 領収書がある時は、必ず封筒に同封してください

👛 日払い

エクセルの記録簿で入れていたのと同じ内容を入れます。キキララから取った／回収金から取った → 「払った」にチェック。日払いは PC で入れます。

🕒 遅刻・早退・欠勤

キャストごとの枠の「勤怠」から、または「今いない」の名前を押して登録します。

📱スマホで受付するとき

1分さわらないと1分でロックがかかります。キャストや近くの人に画面を見られないためです。開けるときは、ロックの合言葉を入れます。
  • スマホで開けるのは、ポータル・受付・精算・キャスト台帳、内勤カレンダー、在籍作成ルームです
  • スマホでは、かな検索・今日の数字・日払いはかくれています（画面を見やすくするため）
  • 顧客台帳のページはスマホでは開けません。NG を外すのは受付の画面でできます
  • キャストのいる場所では、画面を出しっぱなしにしないでください

🚪自動ログアウト

内勤カレンダーの退勤時刻の5分後に、自動でログアウトします。退勤の5分前から「まもなくログアウト」と出るので、まだ作業する時は「30分のばす」を押してください。

🆘こまったとき

  • 「登録した端末ではありません」と出た → ブラウザのデータを消した・シークレットウィンドウ・ちがうブラウザ（Chrome と Edge）が原因です。店長に連絡してください
  • NG がまちがっている → 受付の画面で「NGを外す（まちがいだった）」
  • お客さんのデータが少しちがう → 気づいた人が直してOKです
  • 操作がこわい → 上のタブの「🧪 練習」で、何回でも練習できます（黄色い帯が出ている間は練習です）
